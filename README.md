# UDGAMA - JobPortal
# Developed by Gowtham

UDGAMA is an innovative online job portal designed to facilitate seamless interactions between job seekers and recruiters. 
The platform empowers candidates to create profiles, upload resumes, and search for job opportunities while providing recruiters with tools to post job openings and manage applications efficiently.

# Features
User Profiles: Candidates can create and manage their profiles, showcasing their skills and experience.
Resume Upload: Users can easily upload their resumes for recruiters to review.
Job Search: Advanced search functionality allows candidates to filter job listings based on various criteria such as location, industry, and job type.
Job Alerts: Candidates can set up alerts for new job postings that match their preferences.
Application Tracking: Job seekers can track the status of their applications in real-time.
Recruiter Dashboard: Recruiters can post job openings, view applications, and manage candidate communications from a centralized dashboard.
Analytics: Admins can access analytics to monitor job postings, candidate engagement, and overall platform performance.

# Technologies Used
UDGAMA is built using a robust technology stack:
Backend: J2EE, Servlets, JDBC, Java
Frontend: jQuery, HTML, CSS, JavaScript
Database: MySQL
